## What is dominik-ui?

**dominik-ui** is my personal registry of reusable, accessible React components.
Every component is shadcn-compatible, so you install it straight into your
codebase with the shadcn CLI — you own the code, there is no runtime dependency
to track.

The components live at `dominikkoch.dev/r` and are distributed as plain
TypeScript + Tailwind files built on Base UI primitives and `motion`.

## Setup

Add the registry to your `components.json` so the CLI can resolve the
`@dominik-ui` namespace:

```json title="components.json"
{
  "registries": {
    "@dominik-ui": "https://dominikkoch.dev/r/{name}.json"
  }
}
```

Then install any component by name:

```bash
npx shadcn@latest add @dominik-ui/expandable-tabs
```

## Components

- [Expandable Tabs](/ui/docs/expandable-tabs) — animated icon tabs with a sliding
  active pill and an expanding label.
- [Braille Loader](/ui/docs/braille-loader) — an animated braille loading
  indicator with four variants.

## Requirements

- React 19+
- Tailwind CSS v4
- A shadcn-initialised project (`npx shadcn@latest init`)
